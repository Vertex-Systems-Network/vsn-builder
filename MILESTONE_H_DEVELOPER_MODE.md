# Milestone H — Developer Mode Guardrail

VSN remains in Developer Mode for Milestone H.

- Saved Library and Marketplace source separation is local/schema-safe and does not publish storefront content automatically.
- Marketplace installs remain editor resources until a merchant explicitly uses and publishes them.
- Resource imports create draft/local resources and never deploy a theme or publish a page automatically.
- Dashboard Plans remains the authoritative commercial screen; Milestone H does not change production billing.
- No new production credentials, deployment URLs, or irreversible production operations are introduced by this milestone.
