# VSN Builder v2.5.58 — Milestone H.1 Developer Mode

Milestone H.1 consolidates navigation and product naming while the app remains in developer mode.

- Product display name: **VSN Builder**.
- Home and Builder are two focused surfaces inside one Shopify app shell.
- Existing direct routes remain available for backward compatibility and resource loading.
- Role/owner checks continue to run server-side; hiding a menu item is never treated as authorization.
- No production URL, billing activation, or irreversible deployment change is performed by this milestone.
