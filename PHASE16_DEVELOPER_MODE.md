# Phase 16 — Developer Mode Guardrail

Phase 16 is implemented while VSN remains in Developer Mode.

- Paid plans may be simulated locally for testing.
- Production paid plan activation must go through Shopify-managed billing.
- Onboarding demo actions create local editable drafts only.
- Demo flows never publish pages, activate a live theme, charge a merchant, or promote an environment automatically.
- No widget is removed solely because of plan tier; commercialization gates systems/capacity instead.
- Competitive documentation must not publish unverified competitor prices or claims.
