# VSN Developer Sample Store Workflow

The sample-store workflow is intentionally non-destructive in Developer Mode. Builder → Setup can seed editable local drafts for Home, Header, Footer, Collection and Product templates. Nothing is published, assigned to a live theme, or billed automatically.

## Suggested demo sequence
1. Seed **Full Theme** from Builder → Setup.
2. Open the generated Home draft in the visual editor.
3. Reuse a section from Saved Library and apply a Brand Kit.
4. Open the Collection draft and use Loop / Query Builder for products.
5. Preview responsive breakpoints and run System Health.
6. Publish only when the merchant explicitly chooses to do so.

The same workspace can demonstrate localization, components, interactions, managed fonts/SVGs, Forms 2.0 and Marketplace templates without requiring a separate demo runtime.
