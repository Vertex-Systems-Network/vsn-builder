# Canvas → Shopify Native Section Demo

Use an editable VSN section as the source, then open **Builder → Shopify Native** to expose supported VSN sections through the Theme App Extension. The native bridge uses the same VSN schema and renderer; it does not convert all widgets into independent Shopify blocks.

Demo checkpoints: create/edit the VSN section, publish through the native bridge, add it from Shopify Theme Editor, confirm isolation between section instances, and verify removal/reinstall safety.
