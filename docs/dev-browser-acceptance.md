# Real Chromium Dev acceptance, no merchant authentication
CI boots a **compiled** `VSN | Builder (Development)` React Router app with an ephemeral SQLite database and synthetic Shopify IDs on `127.0.0.1`. It uses pinned Playwright `1.64.0` to run Chromium in desktop (1440×900) and mobile (390×844) layouts with screenshots of the synthetic homepage. All external network traffic is blocked at the browser context level. Browser checks cover the exact Dev title, login form input, viewport overflow, and protected dashboard/pages/editor routes (which must deny/redirect without a session); unrecognized paths return 404.

The browser runs only in a GitHub Actions Linux job; it installs Playwright without altering the application's tracked package files or introducing a normal app dependency, then deletes the temporary runner. Screenshots contain **no merchant data**. This does not represent an authenticated Shopify merchant dashboard or a functional editor canvas test. A real dedicated Shopify Dev Client ID, tunnel and development store remain required for those tests. Staging and Production Workers and Neon projects are not accessed, and this workflow never deploys or publishes.
