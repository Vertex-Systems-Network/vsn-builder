# Shopify Cloudflare Worker SDK configuration contract (no deployment)

`app/services/shopify-worker-configuration.js` verifies the **canonical VSN Shopify scopes**, exact Staging/Production Client ID constraints, Worker/Neon project identities, billing test mode, real HTTPS app origin and incoming Request origin before offering a configuration to an injected Shopify SDK initializer. SDK options include online sessions, auth path and 2026-07 API version. Tests use **dummy** Client IDs, secrets and a mocked session storage/SDK factory only; errors are sanitized.

This module is **not itself a working Shopify Cloudflare adapter**. The repo currently uses `@shopify/shopify-app-react-router/adapters/node`; the corresponding upstream Cloudflare wrapper adapter is not known to be shipped in the pinned 2.1.0 package (upstream Shopify/shopify-app-js PR #3160 remained open during review). A Cloudflare-compatible platform adapter and persistent Neon-backed session storage must be wired and tested against a development store, plus signed Shopify session validation, GDPR/webhook verification, streaming and Vite bundling. Do not import this in a Worker for public traffic without that certification.

Hosted Cloudflare Workers remain their 503 placeholders, and `workers/app.js` or target `wrangler.*` deploy configurations have **not** been created so release guards remain closed. No secrets, Neon data or Cloudflare Worker deployments involved.
