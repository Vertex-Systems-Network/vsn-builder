# Pages & Templates

Create pages from Pages, edit in the visual editor, validate responsive states, preview, publish, assign resource/default templates, use Trash for reversible deletion, and use permanent delete only after confirmation.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
