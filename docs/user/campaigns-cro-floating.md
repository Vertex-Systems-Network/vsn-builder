# Campaigns, CRO & Floating Elements

Create popups/drawers/flyouts/floating elements, configure triggers, targeting, schedule and frequency caps. CRO experiments support variants, goals, attribution and guarded winner publishing.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
