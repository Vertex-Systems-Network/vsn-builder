# Wishlist Commerce

Anonymous visitors use local persistence; logged-in customers use server persistence with local-to-server merge. Use Wishlist Button, Count, Grid and Empty State widgets and the Wishlist Page starter.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
