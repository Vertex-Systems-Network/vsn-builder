# Saved Library & Marketplace

Saved Library contains merchant-owned pages, sections and components. Marketplace contains VSN-supplied resources. Import packages through inspect → validate → dependency check → conflict preview → ID remap → import → verify.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
