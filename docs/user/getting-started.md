# Getting Started

Use Setup → build → validate → reuse → publish. Keep Theme App Embed enabled on the published theme, run System Health before publishing, and keep merchant-created resources in Saved Library rather than Marketplace.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
