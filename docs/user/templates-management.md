# Templates Management

The Templates screen manages builder pages and reusable storefront templates in List or Grid view.

- The default database page size is 12 records.
- Search first filters the currently loaded page immediately, then runs a database search to ensure complete results.
- Status, date, SEO score, template type, author and sorting controls are applied by the server query.
- Bulk actions work on selected records and include Delete, Draft, Scheduled and Publish. Scheduling uses VSN date/time UI rather than browser prompts.
- The floating Page Settings control manages summary widgets, table columns, records per page and the preferred List/Grid view.
- Template Image is selected in Editor → Page Settings → Template Image. The same stored image is shown in List and Grid.
- Rename uses a VSN modal. Delete/default changes use VSN confirmation UI.
- Publishing still obeys role permissions, collaboration locks and approval workflow.
