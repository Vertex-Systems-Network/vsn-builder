# Global CSS & JavaScript

Developer Studio Global Code supports storefront/page/market/locale scopes, execution locations, priorities, revisions, rollback, Safe Mode and warnings. Keep JavaScript minimal and reversible.

## Checklist

- Confirm the relevant VSN permission.
- Test loading, empty and error states.
- Validate light/dark UI where applicable.
- Run System Health if Shopify/API data is unavailable.
- Preview before publishing or enabling storefront behavior.
