# UI Standards

VSN has two intentional profiles.

## Workspace profile
Resource management, settings, System Health, Marketplace and dashboard surfaces. Use consistent headers, cards, filters, pagination, notices, confirmation and empty/loading/error patterns.

## Editor profile
Canvas, topbar, left insert sidebar and inspector. Compact density and stable geometry take priority. Content, Style and Advanced controls must remain schema-isolated.

## Visual stability
Milestone releases must not redesign an existing screen incidentally. If a functional change requires a visual change, document it. Pricing/Plans retains its established centered header, billing switcher, highlighted cards and FAQ rhythm while Phase 16 entitlements remain the data source.
