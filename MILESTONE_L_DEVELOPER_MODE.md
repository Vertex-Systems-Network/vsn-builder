# Milestone L — Permissions 2.0 (Developer Mode)

Status: COMPLETE
Version: 2.5.68
Based on: v2.5.67
Date: 2026-08-08

This package remains in Developer Mode. Milestone L does not enable production billing, deploy irreversible production changes or widen Shopify scopes automatically.

Included:
- resource/action permission contracts layered on top of existing VSN systems,
- server-side enforcement for Pages, Marketplace, Developer Studio, Plugin SDK and Billing,
- owner-configurable Role Manager action toggles,
- owner full-access guarantee,
- Developer Studio / Plugin SDK explicit-grant model for non-owner roles,
- UI capability gating for page editing/publishing/deletion and billing/developer actions,
- idle-session runtime stabilization and React list-key cleanup carried into the Milestone L baseline.
