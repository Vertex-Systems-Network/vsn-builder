# Milestone J — Developer Mode

Version: **2.5.63**

Developer Mode remains enabled for this milestone.

- No paid-plan activation is simulated as production billing.
- Widget Studio and SDK 2.0 changes are validated against the local development database and Shopify development session.
- Theme App Embed status is observational: only a verified enabled embed is labelled **Theme Active**.
- A missing/failed Theme verification uses danger styling and links the merchant to Shopify Theme Editor; VSN does not silently enable the embed.
- Widget templates and custom widgets contain no arbitrary JavaScript execution path.
