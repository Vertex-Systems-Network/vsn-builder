# Milestone P.2 — Developer Mode

VSN remains in Developer Mode. P.2 adds platform-quality inspection and reference motion presets without production deployment/billing changes.

- Structural visual baselines are merchant-scoped and local to VSN settings.
- Pixel visual regression requires an explicitly configured authenticated test URL.
- Performance budgets are advisory.
- Extension sandbox evaluation does not install code.
- Migration simulator is dry-run only.
- Reference animation libraries are not bundled as runtime dependencies; VSN ships native Motion timelines inspired by their named effects.
