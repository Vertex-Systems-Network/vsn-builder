# Milestone M.2 — Developer Mode

Version: **2.5.71**

This package remains a developer-mode milestone. It completes Wishlist Commerce server persistence and page-building primitives, expands Motion Library, and fixes Developer Studio code-editor contrast. It does not enable production billing or make irreversible merchant-theme changes.

## Wishlist

- Signed Shopify app-proxy customer identity is authoritative for server persistence.
- Anonymous state remains local-first.
- Login merges local and server lists and saves the canonical result.
- Wishlist Grid and Empty State are first-class widgets.
- Marketplace includes an editable Wishlist Page starter.
- Customer/shop redact lifecycle handlers and uninstall cleanup remove persisted wishlist records.

## Motion

- Complete 97-name Animate.css catalog recreated in VSN Motion schema.
- 960 additional generated VSN presets.
- 1,063 built-in presets total with incremental UI rendering.

## Developer Studio

Light and dark appearances explicitly set source, caret, selection, toolbar and suggestion colors for code editors.
